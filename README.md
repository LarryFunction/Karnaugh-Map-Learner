# 卡诺图学习器 · Karnaugh Map Learner

一个零依赖的单文件网页应用，用于演示与学习**卡诺图（Karnaugh Map）**，
重点帮助理解 **布尔真值表 → 卡诺图 → 最简布尔表达式** 三者之间的对应关系。

直接双击 `index.html` 即可在浏览器中打开，无需安装任何依赖或构建步骤。

## 功能特性

- **真值表 ↔ 卡诺图 ↔ 表达式 实时联动**
  在任意一处修改取值，其余视图立即同步更新。
- **交互式卡诺图**
  点击格子即可编辑；圈组以彩色边框绘制，支持边缘环绕（wrap-around）。
- **自动化简**
  自动枚举质蕴含项并求最小覆盖，输出最小与或式（SOP）与文字数统计。
- **圈组可视化**
  每个圈组一种配色；鼠标悬停右侧列表可高亮对应圈组，直观看出如何消去变量。
- **无关项（don't care）**
  用 `X` 表示无关项，化简时可自由当作 `1` 使用。
- **支持的规模**
  2 ~ 4 个输入变量。

## 使用方法

1. 用浏览器打开 `index.html`。
2. 在工具栏选择变量数（2 / 3 / 4）。
3. 选择画笔：`切换`（循环 `0 → 1 → X`）、`1`、`0` 或 `X`。
4. 点击**真值表 F 列**或**卡诺图格子**设置取值。
5. 观察右侧自动生成的标准与或式与最小与或式，以及每个圈组消去了哪些变量。

### 工具栏说明

| 控件 | 作用 |
| --- | --- |
| 变量数 | 在 2 / 3 / 4 变量之间切换（切换会重置取值） |
| 画笔 | 选择点击时写入的值；`切换` 会循环取值 |
| 示例 | 载入预设，如全 0、全 1、随机、棋盘、前半区、相邻两格 |
| 清空 | 将所有格子置为 0 |
| 显示全部质蕴含项 | 在最小覆盖之外，额外显示所有质蕴含项以便对比 |

## 卡诺图读数约定

- 行、列方向的格雷码顺序保证相邻格子只相差一个变量。
- 网格的四条边相互相邻（可环绕）：最左与最右列相邻，最上与最下行相邻。
- 圈组大小必须是 2 的幂（1、2、4、8、16 格），且为矩形。
- 圈组越大，可消去的变量越多；被圈组覆盖的取值中，取值不变的变量保留，变化的变量消去。

## 实现说明

- 纯 `HTML + CSS + JavaScript`，全部代码位于单个 `index.html`。
- 卡诺图布局：2 变量 `1×1` 位分割，3 变量 `1×2`，4 变量 `2×2`（行位 / 列位）。
- 化简算法思路（`analyze` / `minimalCover`）：
  1. 枚举所有乘积项（每个变量取 `0` / `1` / 无关）；
  2. 保留只覆盖 `1`（或 `X`）且至少覆盖一个 `1` 的蕴含项；
  3. 提取质蕴含项（不被任何更大的蕴含项包含）；
  4. 对必须覆盖的所有最小项做精确最小覆盖搜索，得到最小与或式。
